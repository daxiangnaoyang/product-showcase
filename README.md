# product-showcase

跨 Agent 的产品展示内容工作流 Skill。

它把产品图片与文字说明整理为一套可审阅、可迭代的内容包：

产品事实卡 → 推荐语 → 电商卖点图解 → 朋友圈短文与配图 → 15 秒产品卖点视频脚本或成片。

## 触发词

- 产品介绍
- 产品说明
- 产品视频
- 产品图文
- 推荐语
- 种草文案
- 朋友圈分享
- 产品卖点

## 主要能力

- 收集产品图片、文字说明、卖点、受众、场景和平台要求。
- 区分用户提供、图片可见、待确认和未获取的信息，避免编造参数、价格、功效或评价。
- 以产品图为身份参考，重构一图一卖点的电商图解。
- 生成推荐语、朋友圈分享短文和适配平台的配图方案。
- 输出精确 15 秒的产品卖点分镜、口播、字幕和视频生产 Prompt。
- 当前 Agent 没有图像或视频能力时，降级为可执行 Prompt、分镜和素材缺口，不虚构成片。

## 使用方式

将整个 product-showcase 目录放入目标 Agent 的 Skill 目录，并让运行时重新扫描 Skill。不同 Agent 的工具名称和能力可能不同，入口文件只依赖能力路由，不依赖某个供应商的专用 API。

正式生成前，先确认产品事实卡、卖点排序、视觉方向和交付范围。没有产品图时，可以先写文案和分镜，但不能把概念图或文生视频描述为真实产品展示。
