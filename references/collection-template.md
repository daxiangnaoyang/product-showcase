# 产品信息收集模板

用于第一轮向用户一次性收集必要信息。用户已经提供的字段不要重复询问；不会回答的字段写“待补充”，不要自行填值。

## 第一轮可直接发送

我先收集产品素材，再按你的选择制作推荐语、电商卖点图解、朋友圈短文/配图和 15 秒产品介绍。请尽量一次提供：

### A. 产品事实

| 字段 | 请提供 |
|---|---|
| 产品名称 | 产品叫什么？ |
| 品类 | 属于什么品类？ |
| 核心卖点 | 最重要的 2—5 个卖点，请按优先级排序 |
| 目标人群 | 主要卖给谁？年龄、身份或典型场景均可 |
| 使用场景 | 在什么场合使用？解决什么具体问题？ |
| 价格/优惠 | 仅在需要写入文案或图片时提供；没有就写未提供 |
| 规格/材质/成分 | 尺寸、容量、材质、成分、续航等，只填已确认信息 |
| 品牌/店铺 | 品牌名、店铺名、Slogan；Logo 需要使用时请提供官方文件或明确授权 |
| 售后/限制 | 保修、适用人群、禁用场景或不能承诺的内容 |

### B. 图片与其他素材

- 请上传 1—6 张产品图；优先包含正面、侧面、细节、包装和实际使用场景。
- 如果有必须保留的 Logo、标签、接口、纹理、颜色或包装文字，请指出。
- 请说明哪些图片可以用于编辑、哪些只能参考。
- 若产品图中有小字或参数，请同时提供文字版，避免 OCR 误读。

### C. 本次要做什么

- 需要哪些产物：推荐语 / 电商卖点图解 / 朋友圈短文 / 配图 / 15 秒视频脚本 / 视频成片。
- 主发布平台：朋友圈 / 小红书 / 视频号 / 抖音 / 其他。
- 文案口吻：专业种草 / 亲切日常 / 活泼有趣 / 其他。
- 图片比例：1:1 / 4:5 / 3:4 / 9:16 / 其他。
- 视频：默认 15 秒、9:16；是否需要真人出镜、口播或字幕。
- 是否有必须避开的词、承诺、竞品或视觉元素。

## 创作前事实卡

收集后整理为以下结构，并把缺口显式列出：

| 字段 | 内容 | 证据状态 |
|---|---|---|
| 产品与品类 |  | 已提供 / 图中可见 / 待确认 / 未获取 |
| 目标人群与场景 |  | 已提供 / 待确认 / 未获取 |
| 卖点 1—5 | 功能 → 用户利益 | 已提供 / 待确认 |
| 参数、价格、优惠 |  | 已提供 / 未获取 |
| 可见外观 | 颜色、轮廓、结构、材质外观、Logo | 图中可见 |
| 不可从图中确认的内容 |  | 未获取 |
| 不能使用的表达 | 医疗、保证、绝对化、未经授权的比较等 | 已确认 / 待确认 |
